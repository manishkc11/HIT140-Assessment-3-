# PRT565 Assessment 3: FIFA World Cup 2026 Analysis

## 1. Project Overview

This project is part of the PRT565 Assessment 3 group assignment at Charles Darwin University.

The project uses Python and linear regression to analyse FIFA World Cup 2026 football match data. It investigates whether pre-match team statistics can help predict match goal difference and the number of goals scored by a team.

## 2. Project Objectives

### Linear Regression 2.1

The first model predicts the goal difference for each match.

- Dataset: `regression_2_1.csv`
- Expected observations: 104 matches
- Target variable: `Goal_Difference`
- Number of explanatory variables: 8

### Linear Regression 2.2

The second model predicts the number of goals scored by an individual team in a match.

- Dataset: `regression_2_2.csv`
- Expected observations: 208 team-match observations
- Target variable: `Goals_Scored`
- Number of explanatory variables: 8

## 3. Technologies and Libraries

The project uses the following Python libraries:

- Pandas for data processing.
- NumPy for numerical operations.
- SciPy for scientific computing.
- Scikit-learn for linear regression and model evaluation.
- Matplotlib for data visualisation.
- OpenPyXL for Excel file support.

The required package versions are listed in `requirements.txt`.

## 4. Project Structure

- `main.py`: Main Python script for data validation, model training, evaluation and visualisation.
- `build_datasets.py`: Script for preparing the two regression datasets.
- `requirements.txt`: Required Python libraries and versions.
- `data/`: Source and prepared CSV datasets.
- `results/`: Model metrics and prediction outputs.
- `figures/`: Visualisations generated by the Python scripts.
- `README.md`: Project documentation.

## 5. How to Run the Project

1. Install Python 3.
2. Open the project folder in Visual Studio Code.
3. Open a terminal in the project folder.
4. Install the required libraries by running:

   `python3 -m pip install -r requirements.txt`

5. Ensure the required source dataset is saved in the `data` folder.
6. Prepare the datasets by running:

   `python3 build_datasets.py`

7. Run the regression analysis by running:

   `python3 main.py`
