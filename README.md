
# HIT140 Assessment 3 – FIFA World Cup 2026 Regression Analysis

## Project Overview
This repository contains the Python code, datasets and analysis for HIT140 Assessment 3, Objective 2.

**Regression 2.1:** Predict the goal difference between two opposing teams using 104 FIFA World Cup 2026 matches and eight pre-match explanatory variables.

**Regression 2.2:** Predict the number of goals scored by an individual team using 208 team-match observations and eight pre-match explanatory variables.

## Team Contributions
- **Enosh – Member 1:** Data preparation and exploratory data analysis
- **Manish – Member 2:** Multiple linear regression model development and training
- **Suraj – Member 3:** Model evaluation and diagnostics
- **Himanshu – Member 4:** Interpretation and discussion

## Technologies
Python, pandas, NumPy, scikit-learn, Matplotlib and Jupyter Notebook.

## Reproducibility
Each member's folder contains their relevant Python code and supporting files. Open the Jupyter notebooks and run the cells in order using the required Python libraries.
